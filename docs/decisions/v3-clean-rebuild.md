# V3 Clean Rebuild Decision

V3 is a clean rebuild of the hot-topic project. The previous V2 code remains available on the `v2` branch.

The V3 branch keeps only a small project skeleton focused on:

- User profiles.
- Profile-derived topic queries.
- Platform hot-list providers.
- Normalized hot items.
- Topic clusters.
- Human-readable reports and machine-readable datasets.
