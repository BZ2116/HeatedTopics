# HeatedTopics V3

HeatedTopics V3 collects platform hot-list records for a user profile, filters them with profile-derived topic queries, and outputs:

- A human-readable topic report.
- A structured dataset for downstream projects.

V3 starts with `juejin`, `bilibili`, and `baidu`, then expands to `weibo`, `toutiao`, and `zhihu`.

`xiaohongshu` is intentionally excluded because another project handles it.
